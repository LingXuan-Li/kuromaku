# InfoBoard

This system is the server of Shuho Sports Fes. Information Dashboard.

## Copyright

Copyright (c) 2026 LingXuan-Li

## Main Language

Python 3.14.4 + Flask

## How to use it?

1. Clone or download the repository

2. Navigate to the project directory

3. Install dependencies: `pip install -r requirements.txt`

4. Run the application: `python main.py`

5. Access the dashboard at [localhost:5000](http://localhost:5000)

## Technical Stack

**Backend:** Python 3.14.4 with Flask framework
**Database:** SQLite for message storage, CSV for data files
**Frontend:** HTML5, CSS3, JavaScript
**Data Format:** CSV for easy Excel compatibility
